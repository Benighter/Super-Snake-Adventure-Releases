# Super Snake Adventure for Windows

Official Windows installers and update metadata by Benighter Software. The development repository and server credentials remain private.

[Download the Windows installer](https://github.com/Benighter/Super-Snake-Adventure-Releases/releases/latest/download/Super-Snake-Adventure-1.6.8-Windows.exe) · [Release notes and checksums](https://github.com/Benighter/Super-Snake-Adventure-Releases/releases/latest)

The game includes 2D and 3D views, keyboard and controller support, snakes, arenas, pouches, quests and rewards. Sign in to share your verified progress.

Gold packs are 100 Gold for R10, 280 Gold for R25 and 650 Gold for R50. Live sales await Xsolla approval and the tax interview. Earned Gold remains available through play.

The EXE installs the normal Windows app with in-app update checks. The ZIP is an optional unpacked edition. This build is not code signed; Windows may display an unknown-publisher notice.
